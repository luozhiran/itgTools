# 09 场景覆盖矩阵

符号：✅ 直接支持；🟡 通过扩展/手写 runtime 支持；❌ 当前不支持。

## Recycler

| 场景 | 状态 | 入口或限制 |
|---|---:|---|
| ViewBinding 完整绑定 | ✅ | `@ItgViewBindingItem` + 两参数 `@ItgBind` |
| ViewBinding payload 绑定 | ✅ | 三参数 `@ItgBind` |
| TextView 字段自动绑定 | ✅ | `@ItgAutoTextField` |
| 自动生成字段 payload | ✅ | 自动字段差异 |
| 自定义 payload | ✅ | `@ItgPayload` |
| 自定义内容比较 | ✅ | `@ItgContentsSame` |
| DataBinding Item | ✅ | `@ItgDataBindingItem` |
| DataBinding 不声明 actions variable | 🟡 | 注解生成暂不支持；手写 registry 可用 |
| ViewBinding + DataBinding 混合列表 | ✅ | 使用相同 actions 类型 |
| 一个模块多个 adapter | ✅ | 使用不同 actions 类型分组 |
| 无业务回调 | ✅ | 定义空 actions 对象 |
| Activity 列表 | ✅ | LifecycleOwner 使用 Activity |
| Fragment 列表 | ✅ | 使用 `viewLifecycleOwner` |
| LiveData 自动提交 | ✅ | `RecyclerViewAbility.observeItems` |
| 手动提交列表 | ✅ | `RecyclerController.submitList` |
| 自定义 onRecycled | 🟡 | 手写 registry |
| 自定义 Renderer / bindPayload | 🟡 | 手写 registry |
| Compose Item | ❌ | 当前生成器和 itg-ui renderer 面向 ViewBinding/DataBinding |

## Tab

| 场景 | 状态 | 入口或限制 |
|---|---:|---|
| Activity Host | ✅ | `@ItgTabHost` + `TabHostActivity` |
| Fragment/嵌套 Host | ✅ | `@ItgTabHost` + `TabHostFragment` |
| 直接或间接 Fragment 子类 | ✅ | 递归继承识别 |
| 文本标题 | ✅ | `title` |
| 资源标题 | ✅ | `titleResExpression` |
| 资源图标 | ✅ | `iconResExpression` |
| 动态 Drawable 图标 | 🟡 | 对生成列表 `copy` 或手写 TabItem |
| Fragment arguments | ✅ | `argumentsExpression` |
| 数字角标/红点 | ✅ | `badgeCount` / `badgeDot` |
| 高级角标样式 | 🟡 | 对生成列表 `copy` |
| Tab 行为配置 | ✅ | `@ItgTabHost` 参数 |
| TabStyle | 🟡 | 对生成 TabConfig `copy` |
| onPageSelected | 🟡 | 对生成 TabConfig `copy` |
| 动态更新角标 | ✅ | `tabViewPager.updateBadge` |
| 动态增删 Tab | ❌ | 当前 Host/Ability 按一次性列表绑定设计 |
| 同包同 group 多 Host | ❌ | 会发生生成文件同名冲突 |

## 构建

| 场景 | 状态 | 说明 |
|---|---:|---|
| debug/release | ✅ | 各变体独立生成 |
| 自定义 build type | ✅ | 执行对应 KSP task并注册生成目录 |
| Android library 内生成 | ✅ | KSP 依赖配置在该 library |
| 手改生成文件 | ❌ | 后续构建会覆盖 |
