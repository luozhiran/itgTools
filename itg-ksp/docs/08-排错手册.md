# 08 排错手册

## 1. `Unresolved reference 'GeneratedXxxRegistry'`

先判断是 Gradle 编译错误还是 IDE 标红：

```powershell
.\gradlew.bat :app:kspDebugKotlin :app:compileDebugKotlin
```

如果命令成功，只是 IDE 标红：

1. 确认 Android Studio Build Variant 是 debug。
2. 确认业务模块显式注册了对应 KSP 目录，参见 [01](./01-接入与构建配置.md)。
3. Sync Project with Gradle Files。
4. 最后再使用 Invalidate Caches。

如果命令失败，优先看 `kspDebugKotlin` 输出，而不是只确认旧生成文件存在。`build/generated` 中的文件可能是上次构建遗留物。

## 2. 完全没有生成文件

检查：

- 业务模块应用了 `com.google.devtools.ksp`。
- `ksp(project(":itg-ksp-compiler"))` 写在声明注解的模块。
- Provider 服务文件存在并包含处理器 Provider 类名。
- 当前变体对应的 KSP task 实际执行。
- 注解类来自当前 `itg-ksp-annotations` 依赖。

## 3. Recycler registry 没生成

只有扫描到合法 ViewBinding/DataBinding Item 才生成 registry。常见原因：

- Item 未实现 `ItgListItem`。
- ViewBinding Item 没有 `@ItgBind` 或 `@ItgAutoTextField`。
- 注解参数的 actions 类型拼错。
- 查看的是错误 actions 对应的生成名称。

## 4. Tab 函数没生成

Tab 同时满足以下条件才生成：

- 至少一个 `@ItgTabHost`。
- 至少一个同 group 的 `@ItgTabItem`。
- Item 直接或间接继承 Fragment。

Host 存在但同组 Item 为空时，处理器不会生成该 Host 的文件。

## 5. 生成文件自身编译失败

字符串参数会原样写进生成代码，重点检查：

- binding/actions 是否完整限定名。
- layout、BR、icon、titleRes 表达式是否完整且存在。
- arguments 表达式是否使用完整限定名。
- `groupName` 是否能组成合法函数名。
- `@ItgBind` 第三个参数是否为 `List<Any>`。

直接打开：

```text
<module>/build/generated/ksp/<variant>/kotlin/
```

根据生成代码的具体行定位通常最快。

## 6. `Item 类型 ... 注册了多个 Renderer`

同一个 Item 被注册两次。检查是否同时标注 ViewBinding/DataBinding，或手写 registry 又注册了一遍同类型。

## 7. `未注册 ... ItemRenderer`

提交列表包含不属于当前 actions registry 的 Item。让该 Item 使用相同 `actionsClassName`，或提交给正确 adapter。

## 8. stableId 重复

同一列表内所有 Item 的 stableId 必须全局唯一。不同 Item class 也不能复用 id。

## 9. payload 没触发

检查：

- stableId 和 class 是否保持不变。
- 是否提交了新的不可变对象和新列表。
- `@ItgContentsSame` 是否错误返回 true。
- `@ItgPayload` 是否在变化时返回非 null。
- bind 是否使用三参数签名接收 payload。

## 10. 自动字段不更新

- 属性是否标记 `@ItgAutoTextField`。
- `viewName` 是否等于 binding 属性名。
- 目标 View 是否支持 `.text`。
- 混用 `@ItgBind` 时，手写 bind 是否自行更新了字段。

## 11. DataBinding 创建 adapter 时崩溃

当前注解生成器要求真实的 actions variable；不要保留默认 `actionsVariableExpression = "0"`。详见 [04](./04-Recycler-DataBinding.md)。

## 12. Tab 启动时参数异常

- `defaultPosition` 必须落在生成列表范围内。
- `offscreenPageLimit` 只能是 `-1` 或至少 `1`。
- Host 布局必须存在 TabLayout/ViewPager2 id。
- Fragment Host 的 Activity 必须继承 AppCompatActivity。
